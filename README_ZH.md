# ClipMentor

**把带货参考视频，变成创作者看得懂、拍摄时用得上的拆解教学。**

**简体中文** · [English](README.md)

ClipMentor 帮助创作者和内容团队看懂：**产品价值是怎样被拍出来的，哪些做法可以借鉴，具体怎么拍。** 它把原片、讲解、字幕和画面强调组合成拆解视频，并配上拍摄时可查的文字分镜。

## 可以得到什么

| 需要解决的问题 | 产出物 |
| --- | --- |
| 看懂一条参考视频，不必自己逐处琢磨 | **带讲解的拆解视频**：说明产品价值、拍法作用及值得借鉴的细节 |
| 拍摄时手边有一份参考 | **原片 Storyboard**：按顺序整理原视频的画面、动作和台词 |
| 调整讲解或继续修改作品 | **可编辑工程**：保留原片、配音、字幕、图形和时间线 |

拆解视频解释参考做法背后的理由；原片 Storyboard 忠实记录参考本身。为新视频设计的脚本另行区分，不冒充原片内容。

## 一个讲解点是什么样

以布艺清洁演示为例，讲解可以这样组织：

```text
看什么：演示始终围绕同一处污渍展开。
为什么：观众能把清洁动作和这一处的结果联系起来。
怎么借鉴：使用时让同一位置保持可见，结束后再回到这里拍清结果。
```

讲解把商品、买家的问题和画面证据连起来，不能只剩“这里用了特写”“这个钩子不错”这样的标签。

## 工作方式

```text
参考原片 + 商品资料 + 目标读者
    → 选出值得讲解的重点
    → 准备原片回放与讲解蓝图
    → 核对内容和拍法说明
    → 制作配音、字幕与可编辑视频
    → 看片、修改并确认最终产物
```

原片始终是依据。商品主张、可见结果和建议拍法分别说明，剪辑保留原口播和演示的实际含义。

## 从哪里开始

- **做一份拆解**：准备完整原片、商品资料、目标语言和交付范围，按[随应用分发的流程](src/agent/skills/clipmentor/SKILL.md)进行 Agent 辅助策划与制作。
- **运行或开发编辑器**：阅读[开发说明](DEVELOPMENT.md)，查看环境、服务配置、命令和检查方式。
- **核对产出物**：按[交付检查](src/agent/skills/clipmentor/references/delivery-checklist.md)检查实际视频，以及对应文字和工程。

## 项目状态

ClipMentor 仍在开发中，已有可编辑视频底座、绑定原片的讲解计划和审核工具。目前采用 Agent 辅助与人工内容、成片审核结合的方式，尚未证明可以稳定无人介入地完成全流程，也未验证固定的省时幅度。

工程保存在本地，不代表所有操作都离线。按配置使用的分析、转写、审核和配音服务可能接收任务材料；原片和服务的使用范围须与任务相符。
