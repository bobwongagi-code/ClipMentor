# 关系句规则的实验与回放依据

某组的教学价值依赖已确认的关系时，在该组来源登记中提供具体关系。作者须在现行马来语口播中说清关系，并指出承载它的原句。代码只核对该句是本组现行稿中唯一可定位的非空主讲句。独立读者根据实际口播和证据判断意思，作者可按素材选择句式。

## 首稿实验

每个工程组内使用固定画面和独立作者会话。对照 A、B 的输入原文，B 在 A 的原文末尾只多一句本组关系提示。读者先复述实际稿件与下一条会改的拍法，再核对标尺。表中是逐项复核后的结果。

| 工程 | 检查项数 | 关系项通过 A → B | 全过 A → B | 新会话全过 | 主要失分 |
| --- | ---: | ---: | ---: | ---: | --- |
| JUDYDOLL 第 1 组 | 7 | 4/8 → 7/8 | 4/8 → 7/8 | 7/8 | 棕色没有直接对回盘号 |
| JUDYDOLL 第 2 组 | 9 | 0/6 → 6/6 | 0/6 → 6/6 | 5/6 | 没讲工具与脸部区域同框为何使下手位置可辨 |
| JUDYDOLL 第 3 组 | 6 | 6/6 → 6/6 | 5/6 → 5/6 | 无 | 两组各有一份漏写示范结束后才换角度。时机保留为提示 |
| Green Makes r20 第 3 组 | 5 | 2/8 → 8/8 | 2/8 → 8/8 | 无 | 讲了薄涂、叠涂，没讲浓淡参照如何帮助理解后续选项 |
| NIUMO V7 第 1 组 | 5 | 0/8 → 8/8 | 0/8 → 8/8 | 无 | 漏讲原片文字提供的自动断电说明与手触演示提供的体感信息各自的作用 |

Green Makes 以已确认的 P01–P03 和后续颜色画面为依据。同色的两种涂法用于建立浓淡参照。NIUMO 的手触只能表达现场体感。两个跨工程样本的四格均无证据越界。各工程超过约定的关系项至少多通过 2 份、全过数不下降、证据越界不增加的门槛。

[86 份逐项记录](experiment-runs.json)保留每份的通过项、原始判读、复核判读、代码提交及规则版本。通过项字符串按该组标尺顺序列出，通过项清单也用于重算汇总。每份输入和固定画面可用组内的 SHA-256 核对。稿件摘要以原始 `draft.lines` 的紧凑 UTF-8 JSON 数组为准。各组也保留本地完整原始记录的文件摘要。公开仓库只收录逐项结论和校验摘要，原稿、输入原文、媒体和完整读者回执留在本地。

JUDYDOLL 用的是同一批素材。跨工程实验只覆盖浓淡参照和功能说明与体感分工。长期稳定性、未抽样的镜头类型、返修后通过率、真实配音声长和声画对位仍待验证。模型读者的复述用于检查读者能否从实际稿件领会拍法，最终判读由人抽查。

## 零调用回放

[历史回放证据](zero-call-replay.json)记录运行提交、规则版本和源回执摘要。JUDYDOLL 的三个已确认口播组均通过关系句绑定，删除对应引用的三例均被拦截。另用 13 份已保存的负例和原有读者判读重放内容复核路径。即使指向一句真实口播，未表达关系的稿仍需修。隔离副本回放使用两个本地模拟审核响应，模型服务调用为零。核对了首次返修保留问题、未变更候选不送审、实际引用修正可送审、同一关系缺口再次出现时停止。

仓库内的可复跑回归覆盖缺引用、串组、空正文、旧版引用、内容复核与发布绑定、工作台启动开关和独立审核出站请求。使用项目所需 Node 版本及安装好的依赖运行以下命令。

```sh
npx tsx server/clipmentor/production-creator-quality.verify.ts
npx tsx server/clipmentor/production-teaching-baseline.verify.ts
npx tsx server/plugins/clipmentor-production.verify.ts
```

完整历史回放使用本地保存的隔离副本、原稿与回执。独立审核用例读取发给本机模拟服务的实际请求包，覆盖成稿前和现行马来语稿审核。
