# ClipMentor 每版交付检查记录模板

这是2026-10-13生产工作区模板的仓库便携版。复制到本次任务支持的记录位置后填写，不直接把本模板当成检查结果。参照[复现经验](reproduction-lessons.md)及[蓝图流程](planning.md)；必要时按[复现流程](approved-reproduction.md)执行。不要假设本机父目录文档在其他同事环境中可访问。各项填“通过／不通过／未检查／不适用”，通过必须有依据；不能默认勾选，不能以旧版记录覆盖改动后的实际状态。

## 1. 本版范围与不变项（动手前填）

- 版本、最终文件路径、检查日期、检查人：
- 投放对象：新建联／已合作；本版行动目标：
- 原片、参考片、产品资料与最新用户素材：
- 本次授权修改：
- 必须保留的已认可内容：结构、口播、时长、气口、布局、短标签、卖点、Storyboard 等，按本次实际列出。
- 当前视觉基准：背景、同类标签样式、字幕层级、原片标识、重点框／箭头。写明来源，不凭记忆重设。
- 本次重点防复发编号：

### 执行交接与范围检查

- 任务类型：新创作／局部修改／已认可作品复现。工具链试验如另有要求，单独标明，不替代成片效果目标。
- 效果基准及实际可访问位置：认可成片或已批准蓝图版本；迁移稿、试验稿不自动升为基准。
- 执行目标：工程、序列、达人阶段及其对应输出；双版本分别登记。
- 可改项／不变项／尚缺的执行信息：不能只交台词、卖点和总时长，让执行者自行重设计已认可布局。
- 主 Agent 发给执行者的任务是否保留上述约束：检查后填写。复现已有分层工程优先复制复用；不以证明 Agent 会搭建为由禁止复用。

这些信息由 Agent 从已有上下文整理，不要求用户重新填写或重复确认。基准不可访问时可继续安全准备，但不能凭记忆声称复现。

### 分阶段检查结果

| 关口 | 本次结果／证据 | 未通过时处理 |
| --- | --- | --- |
| 开工前 | 基准、范围、两版目标和素材可访问性 | 补缺失信息，不擅自换基准或设计 |
| 扩展前（新建或重建表现方式时） | 代表段实际呈现的构图、文字、标注及交接；每种不同 CTA 单独核对 | 缺关键元素或明显错配先修该段，不复制问题到整片；不变且已有有效检查的段落不用重复渲染 |
| 交付前 | 时间线实例回读＋实际输出对照；复制时核对一致，修正后按预先登记的变更清单核对；显著差异、时间点、处理结果；听审／连续观看分别登记 | 有明显未授权偏离不报效果达标；缺检查只交限定预览，不报完整验收 |

检查按观看效果决定优先级，不追求像素或采样级同一。关键卖点、信息层级、可读性、声音清楚和连贯性不能省略；不影响这些的细小字边／线宽差别不驱动新一轮重做。这是工作流要求，不是已经实现的程序自动导出拦截。

## 2. 产品与段落覆盖（写稿前填，交付前回查）

| 购买理由／核心卖点 | 原片位置及关键数字 | 本段必须讲清的关系 | 讲解口播 | 醒目文字／可见动作 | 成片时段 | 结果／证据 |
| --- | --- | --- | --- | --- | --- | --- |
| 待填 | | | | | | 未检查 |

区分原片说了、女声说了、画面写了。不能用“原片出现过”代替重点已经解释，也不能遗漏产品核心功能而只谈剪辑手法。

## 3. 每句实际声画对应（用最终成片检查）

| 成片时间 | 实际听到的口播／未听审则明确标记 | 字幕 | 中文含义 | 同时出现的画面与动作 | 框／箭头／短标签及原片残字 | 含义及时机是否一致、证据 |
| --- | --- | --- | --- | --- | --- | --- |
| 待填 | 未听审 | | | | | 未检查 |

- 正常速度连看最终视频，确认整段能理解；再检查每句重点与交接点。字幕截图、音频时长、ASR、哈希只能辅助，不能独立证明听感与语义通过。
- 强对应动作必须落在对应话语处；泛原理也须留在同一卖点的解释中，不借其他卖点画面填时长。
- 原声切点、镜头切点、烧录字幕边界分别检查；原声与旁白不叠播，不吞字。只看画面不得标记音频通过。
- 只有文案可读不能声称口音自然、无漏读。工具能力不足时明确未听审，列给本地同事复核；成片可交预览，不宣称最终音画验收通过。

## 4. 成片逐项检查

| 项目 | 要看的实际结果 | 状态 | 证据位置／未检查原因 |
| --- | --- | --- | --- |
| 全片逻辑 | 产品→购买理由→完整表达段落→解释→适合对象的 CTA；不碎、不漏核心关系 | 未检查 | |
| 量化卖点 | 数字、单位、周期、对象准确，关键卖点醒目；原片、女声、标签分清 | 未检查 | |
| 切点与速度 | 无意外闪帧、残字；动作／话句完整；无凑时长慢放 | 未检查 | |
| 静帧与重复 | 每次停留／回看有信息任务，不用无变化画面撑长口播 | 未检查 | |
| 原声到讲解 | 画面能识别“正在解释”，气口自然、不截字、不叠声；不只靠换音色 | 未检查 | |
| 视觉一致性 | 同类背景和标签符合本版基准，所有 Video asal 逐处检查，两版 CTA 对照 | 未检查 | |
| 标注 | 箭头尖端／框指向正确；变换后不漂移，目标到位才出现，原有短句未丢失 | 未检查 | |
| 构图与过渡 | 多框展开、切换过程自然；字可读、不遮主体，没有套框或多余品牌贴标 | 未检查 | |
| 补充素材 | 如使用：有信息增量、与当前口播对应、本地可理解，不冒充原片／新闻／测试 | 未检查 | |
| CTA 与素材 | 新建联联系，已合作开拍；最新指定图正确，已有支持信息未被换图误删 | 未检查 | |
| 结尾 | 达人 CTA 后结束，没有再次附完整原片 | 未检查 | |
| Storyboard | 原爆款而非拆解片；三列、完整信息、可照拍、无点评、Rootify 署名正确 | 未检查 | |
| 实际听审 | 最终音轨发音、漏读、断句、语速、音量和逐句画面对齐分别检查 | 未检查 | |
| 技术完整性 | 最终文件能完整解码，音视频轨存在，帧数／时长／规格与计划一致 | 未检查 | |
| 版本回归 | 本次改动已体现，授权范围外的已认可部分没退化，字幕稿与最终输出同版 | 未检查 | |

单一产品的秒数、画面数或颜色不作为通用判废阈值。局部改动优先检查受影响段落与边界，再通看最终版本，避免检查扩大成无依据的重新制作。未改音轨可证明声音没有被改，不能代替此前从未做过的听审。
